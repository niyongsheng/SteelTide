# Steel Tide · 坦克生存

基于 Kenney《Top-Down Tanks (Remastered)》素材的无尽波次生存坦克游戏，Vite + Phaser 3，桌面 / 手机双端可玩。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 http://localhost:5173/）。
手机真机测试：手机与电脑连同一 Wi-Fi，访问终端里显示的局域网地址（如 `http://192.168.x.x:5173/`）。

## 操作

| 设备 | 操作 |
| --- | --- |
| 桌面 | WASD / 方向键移动，鼠标瞄准，左键或空格开火，M 静音 |
| 手机 | 左半屏虚拟摇杆移动，右半屏摇杆瞄准并开火 |

## 玩法

- **无尽波次**：敌人一波波从地图边缘涌入，波数越高敌人越强、种类越多（沙色 → 绿 → 蓝 → 红 → 暗色 → 精英 → 重装）
- **掉落道具**（敌人死亡掉落，8 秒内拾取）：
  - 三连发 / 速射 / 穿透（限时武器强化，生效时炮塔换装）
  - 回血 / 护盾（吸收一次伤害）/ 全屏清场
- **波间升级**：每波清完后三选一（伤害 / 射速 / 移速 / 血量），点数 1/2/3 或点击选择
- **结算**：被击毁后展示波数、击杀、分数，历史最佳保存在浏览器 localStorage

## 项目结构

```
├── index.html
├── public/assets/        # 从素材包复制的 PNG（"Default size"）
├── src/
│   ├── main.js           # Phaser 配置（FIT 缩放、物理、场景注册）
│   ├── scenes/
│   │   ├── BootScene.js      # 素材加载 + 进度条
│   │   ├── BattleScene.js    # 战斗主体：地图/坦克/子弹/敌人/波次/道具/升级 UI/HUD
│   │   └── GameOverScene.js  # 结算画面 + 重开
│   └── js/
│       ├── Joystick.js   # 双虚拟摇杆（仅触摸设备显示）
│       └── Audio.js      # WebAudio 合成音效（零素材依赖）
```
