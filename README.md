# Steel Tide · 钢铁潮汐

基于 Kenney《Top-Down Tanks Redux》素材的双关卡坦克生存游戏，Vite + Phaser 3，桌面 / 手机双端可玩。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 http://localhost:5173/）。
手机真机测试：手机与电脑连同一 Wi-Fi，访问终端里显示的局域网地址（如 `http://192.168.x.x:5173/`）。

## 关卡

### 第一关 · 新兵训练

草地训练场上的引导式教学关，依次完成 4 个目标：

1. **移动** —— 走到黄色集合点
2. **瞄准与射击** —— 击毁 3 辆靶车
3. **实战演练** —— 击毁 3 辆低速敌方坦克
4. **拾取补给** —— 捡起维修补给

训练模式不会真正阵亡（血量见底会启动训练护盾）。完成后自动解锁第二关，结算面板可直接进入下一关或重练。

### 第二关 · 生存极限

沙漠竞技场中的高强度生存战：

- 敌人从地图四边持续涌入，波次每 18 秒提升一次，血量 / 伤害 / 移速 / 射速随时间持续攀升
- 兵种从沙色侦察兵逐步升级到蓝色猎手、红色重炮、暗影杀手、重装坦克、红色巨兽
- 约 75 秒后出现第一只 **泰坦**，之后约每分钟一只，会发射三向扇形弹幕
- 击杀掉落的补给提供三连发、速射、穿甲、维修、护盾、战术清场、超载等临时能力
- **以生存时间作为唯一得分**（`mm:ss.d`），历史最佳保存在浏览器 localStorage

## 操作

| 设备 | 操作 |
| --- | --- |
| 桌面 | WASD / 方向键移动，鼠标瞄准，左键或空格开火，M 静音，Esc 暂停 |
| 手机 | 左半屏虚拟摇杆移动，右半屏摇杆瞄准并开火 |
| 手柄（标准映射） | 左摇杆 / 十字键移动，右摇杆瞄准，RT/R2（模拟量）或 RB/R1 开火，Start 暂停 |

手柄在菜单、结算和暂停界面使用十字键 / 左摇杆选择，A / Cross 确认，B / Circle 返回；暂停界面中 B / Start / Esc 继续。标准映射的 Xbox / PlayStation / Switch Pro 手柄即插即用，非标准映射手柄可能需要在系统或浏览器层重映射。手柄未连接时自动回退键鼠 / 触摸，不影响原有操作。

手柄支持震动反馈：开火、受击、击毁、拾取、死亡以及菜单焦点变化会触发不同强度和时长的震动，并按优先级避免连续开火时震动过密。不支持震动的浏览器或手柄会自动忽略，不影响游戏。

菜单可用方向键 / `1` / `2` 选择关卡，Enter 确认；结算面板支持 Enter / A 确认当前按钮、`R` 重开、`Esc` / B 返回主菜单。

> 部分浏览器不会把首次手柄按键当作音频解锁手势；如果手柄操作没有声音，按一次键盘或点击屏幕即可恢复。

## 结算与截图分享

第一关训练完成、第二关生存结束后都会在冻结的战场画面上弹出战报；**分享截图仅用于第二关生存结算**。

- 生存时间、击杀数、抵达波次、历史最佳、新纪录提示
- **分享截图（仅第二关生存结束）**：生成一张带品牌页脚的 PNG 战绩海报
  - 优先调用系统分享（Web Share API，手机 / 支持的浏览器）
  - 其次复制图片到剪贴板
  - 最后自动下载为 `steel-tide-survival-*.png`

分享图包含最终游戏画面、战报数据与 `STEEL TIDE · 钢铁潮汐` 页脚。

## 素材使用

全部美术素材来自 **Kenney · Top-Down Tanks Redux**（CC0，见 `License.txt`），已复制进 `public/assets/`，运行时不再依赖原始素材包。

标题与结算大号展示文字使用 **Fusion Pixel Font 12px Proportional (zh-Hans)**（作者 TakWolf，SIL OFL 1.1）。项目内只保留了游戏实际用到的 718 个字符的子集：`public/assets/fonts/steel-tide-pixel.woff2`（约 22KB），许可全文见 `public/assets/fonts/OFL-FusionPixel.txt`。正文与 HUD 继续使用系统无衬线字体，保证小字号可读性。字体项目地址：<https://github.com/TakWolf/fusion-pixel-font>。

本作使用的素材类别：

- **地形**：草地 / 沙地地面、沥青直路、十字路口、T 字分叉、直角弯、土路过渡
- **载具**：蓝 / 沙 / 绿 / 红 / 暗色坦克车身，单管 / 双管 / 三管炮塔，整坦克残骸贴图
- **弹药与特效**：多色炮弹、炮口火光（shot 系列）、爆炸与烟雾序列帧
- **掩体与装饰**：木箱 / 金属箱、红 / 绿 / 黑 / 锈色油桶、沙袋、金属 / 木质路障、红 / 黄色围栏、绿 / 棕色树木、落叶、枯枝、铁丝网、油污、履带印
- **补给**：specialBarrel 1–7 全部用于 7 种战场掉落

## 项目结构

```
├── index.html
├── public/assets/            # 129 张 Kenney PNG + 像素字体子集（自包含）
├── src/
│   ├── main.js               # Phaser 配置（FIT 缩放、物理、截图缓冲、场景注册）
│   ├── style.css
│   ├── scenes/
│   │   ├── BootScene.js      # 素材加载 + 进度条
│   │   ├── MenuScene.js      # 标题页 / 关卡选择 / 历史最佳
│   │   ├── CombatScene.js    # 双关卡共用的战斗基类（移动/瞄准/子弹/敌人/掉落/HUD）
│   │   ├── TutorialScene.js  # 第一关：四步教学目标与训练场
│   │   ├── SurvivalScene.js  # 第二关：计时生存、难度曲线、泰坦与空投
│   │   ├── ResultScene.js    # 结算弹窗 + 战绩截图 / 分享
│   │   └── PauseScene.js     # 游戏中暂停面板（继续 / 重开 / 返回主菜单）
│   └── js/
│       ├── MapBuilder.js     # 草地训练场 / 沙漠竞技场地图构建
│       ├── enemyTypes.js     # 敌方坦克档案与生存模式解锁权重
│       ├── Share.js          # 画面快照 → 战绩海报 → 原生分享 / 剪贴板 / 下载
│       ├── storage.js        # 历史最佳 & 教学完成状态（localStorage）
│       ├── ui.js             # 字体、时间格式、按钮、面板与焦点列表
│       ├── GamepadInput.js   # 手柄轮询、死区、按钮边沿与菜单方向重复
│       ├── Joystick.js       # 双虚拟摇杆（仅触摸设备）
│       └── Audio.js          # WebAudio 合成音效（零音频素材依赖）
```

```js
window.__game.scene.start('Survival')
```
